Relative WIS

In this case, the baseline model is the local model (regular application) with the state model being compared to the baseline. A higher rWIS score (>1) would mean the state model is worse. On the other hand, a smaller rWIS score (<1) means that the state model performed better than the baseline.

state_wis = state_wis |>

complete_wis <- state_wis %>%
